Track 3: External Platform Proof

Independent Host Platform (No Bootstrap, No Savanna CSS)

This page demonstrates that <db-assistant> operates as an isolated, standards-compliant web component inside any external LMS or learning portal without style bleeding or external dependencies.

1. Module Embedding Snippet

<!-- Load the standalone script --> <script src="https://your-platform/db-assistant.js" defer></script> <!-- Place the component --> <db-assistant lang="am" api="http://localhost:8001" content="/data/jobs.json"></db-assistant> <!-- Listen to lifecycle events --> <script> document.addEventListener('db-assistant:question', (e) => console.log(e.detail)); document.addEventListener('db-assistant:escalated', (e) => console.log(e.detail)); </script>
